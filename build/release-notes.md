### New
- **Move a whole tab group.** Drag a group's label to put it somewhere else in the tab bar: before or after another group or a tab outside any group, never inside another group. Its tabs move together and keep their order, and Adar remembers the new order the next time it opens.
- **Move Group Left and Move Group Right** on a group label's menu move the group one place, past the group or tab next to it.

### Install
**macOS** (Apple Silicon): download `Adar-0.21.0-arm64.dmg` and drag Adar to Applications. The first time, macOS asks
whether to open an app downloaded from the Internet: click **Open**.

**Windows** (64-bit): download `Adar-0.21.0-win-x64.exe` and run it. The installer is not signed yet, so SmartScreen
may say "Windows protected your PC"; click **More info**, then **Run anyway**. Needs Git for Windows.

**Linux** (64-bit): download `Adar-0.21.0-linux-x86_64.AppImage`, make it executable (`chmod +x`) and run it (it needs
`libfuse2`), or install `Adar-0.21.0-linux-amd64.deb` with `sudo apt install ./Adar-0.21.0-linux-amd64.deb`.

Already using Adar on a Mac? Use **Adar → Check for Updates…**. Requires Git 2.26 or newer.
