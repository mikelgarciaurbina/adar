First public release of **Adar** — a fast, visual Git client for every repository, public or private. *Adar* means "branch" in Basque.

### Highlights
- Commit graph with coloured lanes, avatars, branch/tag/remote labels, WIP and stash nodes, and search
- Drag a branch onto another to merge, rebase, fast-forward or push
- Staging by file, hunk or line; commit and amend; pre-filled merge messages
- Unified or side-by-side diffs, changed hunks or the full file; file history and blame
- Merge-conflict tool and visual interactive rebase
- Fetch, pull (ff-only / merge / rebase) and push with upstream handling; undo/redo for git actions
- Command palette (⌘P), git console, tabs, dark and light themes
- Works with your existing SSH keys, Keychain and credential helpers; asks before trusting repositories whose config runs commands
- In-app updates (Adar → Check for Updates…)

### Install
Download `Adar-0.1.0-arm64.dmg` (Apple Silicon Macs; Intel Macs are not supported). The app is not signed with an Apple Developer ID yet: the first time, right-click **Adar.app → Open** (or run `xattr -dr com.apple.quarantine /Applications/Adar.app`). Requires Git 2.26 or newer.
