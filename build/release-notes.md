### New
- **Any colour for a tab group.** Besides the eight Basoa colours, a group can take any colour: right-click its
  label and choose *Colour → Custom Colour…*. The picker opens under the label, with the eight colours, a square for
  saturation and brightness, a hue bar, a hex field (`#E8559A`, `E8559A` or `#E59`) and your recent colours.
- The tab bar changes as you pick. **Done**, Enter or a click elsewhere keeps the colour; **Cancel** or Esc puts the
  old one back.
- **Readable in both themes.** Adar keeps the colour you pick and draws it lighter at night and deeper by day, the way
  the eight built-in colours already are, so a pale yellow or a navy still shows and the group's name stays readable.
  The picker shows the group in each theme.
- **New tab group** has a ninth swatch that opens the same picker, and the *Colour* menu lists the custom colours
  other groups use, so two groups can share one in a click.

### Install
**macOS** (Apple Silicon): download `Adar-0.14.0-arm64.dmg` and drag Adar to Applications. The first time, macOS asks
whether to open an app downloaded from the Internet: click **Open**.

**Windows** (64-bit): download `Adar-0.14.0-win-x64.exe` and run it. The installer is not signed yet, so SmartScreen
may say "Windows protected your PC"; click **More info**, then **Run anyway**. Needs Git for Windows.

**Linux** (64-bit): download `Adar-0.14.0-linux-x86_64.AppImage`, make it executable (`chmod +x`) and run it (it needs
`libfuse2`), or install `Adar-0.14.0-linux-amd64.deb` with `sudo apt install ./Adar-0.14.0-linux-amd64.deb`.

Already using Adar on a Mac? Use **Adar → Check for Updates…**. Requires Git 2.26 or newer.
