### Improved
- **A pull request's commits.** The details panel lists them, newest first. Click one to select it in the graph, or
  to open it on GitHub when it is not in your repository yet (a pull request from a fork you have not checked out).
- **Squash and merge** is one button again, with the other ways to merge behind its arrow.
- In *Create pull request*, the remote's name at the bottom sits level with the buttons.

### Install
**macOS** (Apple Silicon): download `Adar-0.9.1-arm64.dmg` and drag Adar to Applications. The first time, macOS asks
whether to open an app downloaded from the Internet: click **Open**.

**Windows** (64-bit): download `Adar-0.9.1-win-x64.exe` and run it. The installer is not signed yet, so SmartScreen
may say "Windows protected your PC"; click **More info**, then **Run anyway**. Needs Git for Windows.

**Linux** (64-bit): download `Adar-0.9.1-linux-x86_64.AppImage`, make it executable (`chmod +x`) and run it (it needs
`libfuse2`), or install `Adar-0.9.1-linux-amd64.deb` with `sudo apt install ./Adar-0.9.1-linux-amd64.deb`.

Already using Adar on a Mac? Use **Adar → Check for Updates…**. Requires Git 2.26 or newer.
